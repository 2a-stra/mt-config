# MikroTik Router Configuration Generator

Generate configuration files for MikroTik routers running RouterOS 7 using a Python-based template and configuration file.

The Python script `gen_mt_config.py` generates RouterOS configuration scripts that can be used for automated router deployment.

## Features

The generated configuration can include:

- IP subnets and address configuration
- DHCP server configuration
- DHCP Options 43 and 66
- L2TP VPN configuration
- OSPF routing over the VPN tunnel
- Firewall configuration

## Requirements

- Python 3
- MikroTik RouterOS 7
- A RouterOS configuration template
- Router-specific configuration values

## Project Structure

A typical project structure is:

```
.
├── gen_mt_config.py
├── mt-template-l2tp.txt
├── mt-config11.py
└── output.rsc
```

`output.rsc` is generated by the Python script and should generally not be edited manually.

## DHCP options 43 and 66

Before generating the router configuration, create the required hexadecimal strings for DHCP Options 43 and 66:

```sh
python3 ./tools/option43.py http://192.168.1.100:8000/config
```

Output:
```
http://192.168.1.100:8000/config

(T)ype = "02"
(L)en = 20 (32 bytes)
(V)alue = 687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967
TLV:
0x0220687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967

CODE43 = "0x0220687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967"
CODE66 = "0x687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967"
```

Add the generated values to the router settings:

```
CODE43=...
CODE66=...
```

These values are inserted into the generated RouterOS configuration during template rendering.

## Router Settings

Create a configuration (`mt-configXX.py`) containing the parameters required for the target router.

Example:
```python
SITE = 11
SITE_NAME = "11"

NET_PRE = "10.0"
MNGT_PRE = "10.2"
CORE_PRE = "10.3"
SIP_PRE = "192.168"
SIP_NET = "192.168.21"
DHCP_START = "192.168.21.10"
DHCP_END = "192.168.22.254"

L2TP_PASS = "ChangePassword"

CODE43 = "0x0220687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967"
CODE66 = "0x687474703a2f2f3139322e3136382e312e3130303a383030302f636f6e666967"
```

Adjust the values according to the network and router being deployed.

## Generate Router Configuration

The generator uses a RouterOS template together with the router-specific configuration values.

```
Usage: gen_mt_config.py [-h] [-o OUTPUT] template config

positional arguments:
  template
  config

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
```

Run the Python script to generate the RouterOS configuration:
```sh
python3 gen_mt_config.py mt-template-l2tp.txt mt-config11.py -o output.rsc
```

Output:
```
Router config: mt-config11.py
Using template: mt-template-l2tp.txt
Writing script: output.rsc
```

The generated configuration is written to `output.rsc`.

## Deploy to the Router

Upload the generated `output.rsc` file to the MikroTik router.

__Important:__ Review the generated configuration before applying it to a production router. Make sure IP addresses, network prefixes, VPN credentials, DHCP settings, and firewall rules are correct for the target device.

### 1. Reset the router and apply the new config script
```sh
/system reset-configuration no-defaults=yes run-after-reset=output.rsc
```

### 2. Create a new admin user
```sh
/user add name="sec" password="Secure-Password123" group=full
```

Import the SSH key from a file:
```sh
/user ssh-keys import user=sec public-key-file=sec.pub
```
__Note:__ The public key file must already be uploaded to the route

### 3. (Optional) Disable the default admin user for security
```sh
/user disable admin
```
